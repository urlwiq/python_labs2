# Лабораторная работа №4 - Интерфейсы и абстрактные классы (ABC)

## 1. Цель работы

Изучение абстрактных базовых классов (ABC) в Python, освоение понятия интерфейса как контракта поведения, закрепление полиморфизма через единый интерфейс.

## 2. Описание интерфейсов

Создано 4 абстрактных класса (интерфейса) в файле `interfaces.py`:

| Интерфейс | Методы | Назначение |
|-----------|--------|------------|
| **IManageable** | `activate()`, `deactivate()`, `get_status()` | Управление состоянием объекта |
| **IMonitorable** | `calculate_load()`, `get_info()` | Мониторинг и сбор информации |
| **IComparable** | `compare_to(other)` | Сравнение объектов между собой |
| **IPrintable** | `to_string()` | Вывод информации об объекте |

## 3. Реализация в классах

### Базовый класс `Server` (из ЛР-3)
Реализует интерфейсы `IManageable` и `IMonitorable`.

### Класс `WebServer`
- Реализует `IManageable` (наследует), `IMonitorable` (переопределяет), `IComparable`, `IPrintable`
- **Сравнение:** по имени хоста (алфавитный порядок)
- **Нагрузка:** базовая + 0.5% за каждый обработанный запрос

### Класс `DatabaseServer`
- Реализует `IManageable` (наследует), `IMonitorable` (переопределяет), `IComparable`, `IPrintable`
- **Сравнение:** по текущей нагрузке
- **Нагрузка:** базовая + 0.3% за каждый выполненный запрос

### Класс `FileServer`
- Реализует `IManageable` (наследует), `IMonitorable` (переопределяет), `IPrintable`
- **Не реализует** `IComparable`
- **Нагрузка:** базовая + 2% за каждый загруженный файл

## 5. Вывод

В ходе лабораторной работы было изучено:

- **Абстрактные базовые классы (ABC)** — создание интерфейсов через наследование от `ABC` и декоратор `@abstractmethod`
- **Интерфейс как контракт** — обязательная реализация определённых методов в классах-наследниках
- **Множественная реализация интерфейсов** — класс может реализовывать несколько интерфейсов
- **Полиморфизм через интерфейс** — единый вызов метода для объектов разных классов
- **Фильтрация по интерфейсу** — отбор объектов по реализуемым интерфейсам с помощью `isinstance()`
