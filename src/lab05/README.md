# Лабораторная работа №5 - Функции как аргументы. Стратегии и делегаты.

## 1. Цель работы

Освоить передачу функций как аргументов, научиться применять встроенные функции высшего порядка (`map`, `filter`, `sorted`), понять концепцию паттерна «Стратегия» и реализовать его на Python, освоить `lambda`-выражения.

## 2. Реализованные функции и стратегии

### Функции для сортировки (стратегии) - 3 шт.

| Функция | Описание |
|---------|----------|
| `by_hostname` | Сортировка по имени хоста |
| `by_load` | Сортировка по нагрузке (возрастание) |
| `by_load_desc` | Сортировка по нагрузке (убывание) |

### Функции для фильтрации - 2 шт.

| Функция | Описание |
|---------|----------|
| `is_active` | Только активные серверы |
| `is_web_server` | Только веб-серверы |

### Фабрика функций

| Фабрика | Описание |
|---------|----------|
| `has_high_load(threshold)` | Создаёт фильтр для нагрузки выше заданного порога |

### Callable-объект (паттерн Стратегия)

| Класс | Описание |
|-------|----------|
| `LoadSortStrategy` | Стратегия сортировки по нагрузке с параметром `reverse` |

### Методы коллекции (расширение из ЛР-2)

| Метод | Описание |
|-------|----------|
| `sort_by(key_func, reverse)` | Сортировка по переданной функции |
| `filter_by(predicate)` | Фильтрация по переданной функции |
| `apply(func)` | Применение функции ко всем элементам |

## 4. Вывод

В ходе лабораторной работы было изучено:

- **Передача функций как аргументов** — сортировка, фильтрация, применение

- **Callable-объекты** — классы с методом `__call__` как стратегии
