# Лабораторная работа №7 - Консольное приложение

| Файл | Назначение |
|------|-----------|
| `main.py` | Загружает данные, запускает CLI, сохраняет при выходе |
| `cli.py` | Отвечает за общение с пользователем (меню, ввод, вывод) |
| `app.py` | Содержит бизнес-логику (добавление, удаление, поиск, сортировка) |
| `storage.py` | Преобразует объекты в JSON и обратно |
| `exceptions.py` | Содержит `ItemNotFoundError`, `DuplicateItemError`, `InvalidInputError` |

## Описание CLI

### Пункты меню

| Пункт | Действие |
|-------|----------|
| 1 | Показать все серверы (таблица) |
| 2 | Добавить веб-сервер |
| 3 | Добавить сервер БД |
| 4 | Добавить файловый сервер |
| 5 | Найти сервер по имени |
| 6 | Найти сервер по IP |
| 7 | Показать активные серверы |
| 8 | Сортировать серверы |
| 9 | Удалить сервер |
| 0 | Выход (с автосохранением) |

### Обработка ошибок

| Ситуация | Обработка |
|----------|-----------|
| Ввод букв вместо числа | `InvalidInputError` → сообщение |
| Дубликат IP | `DuplicateItemError` → сообщение |
| Сервер не найден | `ItemNotFoundError` → сообщение |
| Неверный пункт меню | Сообщение "Выберите от 0 до 9" |

### Сохранение/загрузка

- **При запуске:** автоматическая загрузка из `data.json`
- **При выходе:** автоматическое сохранение в `data.json`
- **Формат:** JSON
