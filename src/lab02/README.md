# Лабораторная работа №2 - Коллекция объектов

## Класс ServerCollection

### Методы
| Метод | Описание |
|-------|----------|
| `add(server)` | Добавить сервер |
| `remove(server)` | Удалить сервер |
| `get_all()` | Получить все серверы |
| `find_by_name(hostname)` | Поиск по имени |
| `find_by_ip(ip)` | Поиск по IP |
| `find_by_status(status)` | Поиск по статусу |
| `remove_at(index)` | Удаление по индексу |
| `sort_by_hostname()` | Сортировка по имени |
| `get_active_servers()` | Получить активные серверы |

### Магические методы
- `__len__()` - длина коллекции
- `__iter__()` - итерация в цикле for
- `__getitem__()` - доступ по индексу

### Сценарий 1: Базовые операции с коллекцией

**Что демонстрирует:** создание коллекции, добавление и удаление серверов, работу магических методов `__len__` и `__iter__`.

**Как работает:** Создается коллекция с именем "Production". В неё добавляются три сервера: "web-01", "db-01" и "cache-01". Через `len()` выводится количество серверов в коллекции. С помощью цикла `for` (который использует `__iter__`) перебираются все серверы и выводятся их имена. Затем сервер "cache-01" удаляется методом `remove()`, и коллекция выводится снова, показывая, что осталось только два сервера.

### Сценарий 2: Поиск и ограничения коллекции

**Что демонстрирует:** работу методов поиска (`find_by_name`, `find_by_ip`, `find_by_status`) и защиту от добавления дубликатов и неверных типов.

**Как работает:** Создается коллекция, в которую добавляются четыре сервера с разными статусами ("active", "inactive", "maintenance"). Демонстрируется поиск сервера по имени "db-master" и по IP "10.0.0.2". Метод `find_by_status` находит все серверы со статусом "active" и выводит их количество. Затем показывается работа ограничений: при попытке добавить сервер с уже существующим IP возникает исключение `ValueError`, а при попытке добавить строку вместо объекта Server — исключение `TypeError`.

### Сценарий 3: Индексация, сортировка и фильтрация

**Что демонстрирует:** доступ к серверам по индексу через `__getitem__`, удаление по индексу методом `remove_at`, сортировку коллекции и фильтрацию активных серверов с созданием новой коллекции.

**Как работает:** Создается коллекция с пятью серверами в случайном порядке имен (zebra, alpha, main, beta, gamma). Демонстрируется доступ к элементам по индексам `[0]`, `[2]` и `[-1]`. Методом `remove_at(1)` удаляется второй сервер. Затем выполняется сортировка `sort_by_hostname()`: серверы упорядочиваются по алфавиту. Метод `get_active_servers()` создает новую коллекцию, содержащую только серверы со статусом "active", что показывает возможность фильтрации и работы с отфильтрованными данными.
